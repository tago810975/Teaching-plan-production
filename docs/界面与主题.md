# 界面与主题

软件界面的设计约定、七套配色主题的风格，以及界面上踩过的坑。**改界面样式、加组件或加主题之前先读这份文档**。
预览中的 A4 页面（`page.css`）属于文档排版，要与导出的 Word 一致，不受这里的任何规定和主题影响。

相关文件：

| 文件 | 内容 |
|---|---|
| `renderer/src/styles/app.css` | 界面全部样式。顶部是设计变量与五套常规主题的基础色；末尾依次是“赤黑”“月潮”两套风格主题的规则 |
| `renderer/src/styles/page.css` | 预览页面排版（不随主题变化，只有 `--page-accent` 一个变量供主题改页面上的悬停提示色） |
| `shared/themes.ts` | 主题登记：编号、名称、设置里色块的颜色、窗口启动底色 |
| `renderer/src/theme/theme.ts` | 当前主题（根元素 `data-theme`）、切换与保存 |
| `renderer/src/theme/CollageText.tsx` | 拼贴字：把短标题拆成逐字的纸片 |
| `renderer/src/theme/tideWater.ts` | 月潮页面切换时的海水图形 |
| `renderer/src/TabTransition.tsx` | 标签页切换的过场（赤黑的斜幕、月潮的海水） |
| `renderer/src/home/SettingsDialog.tsx`、`ThemePicker.tsx` | 首页“设置…”：配色（含风格主题的动效开关）、教学案库位置、导入默认预设、导出选项 |

## 1. 设计约定（所有主题）

- **先用变量，不写死数值**。`app.css` 顶部定义了：线宽 `--hairline`（0.5px，高分屏一个物理像素）、悬停/选中底色
  （`--hover`、`--selected` 等）、字号阶梯（12 辅助 / 13 正文 / 15 标题 / 18 首页大标题）、圆角、浮层阴影、动效时长与曲线。
  组件里不要另写颜色和数值。例外只有文件图标的品牌色、图片缩略图的白底。
- **颜色由基础色推出**。每个主题只覆盖一组基础色（`--desk` 工作台、`--panel` 面板、`--panel-raised` 浮起的面、`--ink` 文字、
  `--ink-soft` 次要文字、`--on-ink` 深色块上的字、`--rule` 线、`--red-pen` 强调色、`--focus` 焦点、`--star` 星级等），
  悬停、选中、通知条底色等都用 `color-mix` 从基础色算出来。新增颜色时先加基础色或推导变量。
- **强调色只有一个**（常规主题是“批改红”），只标当前选中的题目和未保存状态；蓝色只用于焦点框、链接和拖放指示线。
  面板保持平面，阴影只给菜单、工具条和对话框。
- **动效**：浮层出现用 `@starting-style`，只做进入不做退出（关闭立即消失，不拖慢操作）。系统开启“减弱动态效果”或根元素
  `data-reduce-motion="true"` 时全部关闭（`app.css` 中有全局规则）；风格主题里不停循环的动画也各自写了关闭规则。
- **自绘控件**：勾选框（`appearance: none` 自绘，颜色随主题）；下拉框用可定制的原生下拉（`appearance: base-select`，
  Chromium 135+），展开的列表才能加样式与动效，仍是 `<select>`，键盘与读屏行为不变，不要换成自写组件，带 `multiple` / `size`
  的不走这套；行数输入用 `NumberInput`（数字框右侧带 − / +）。
- **主题只改界面**。预览页面始终白纸黑字；深色类主题里公式输入框也保持白底黑字（与预览、Word 中看到的一致）。

## 2. 主题一览

主题存在 settings.json 的 `theme`。主进程启动时读出，作为窗口底色，并通过地址参数 `?theme=` 交给界面，首帧就是对的颜色，
打开时不闪白。切换时根元素临时加 `is-theme-switching`，颜色平滑过渡约 0.24 秒。

| 编号 | 名称 | 类型 | 一句话 |
|---|---|---|---|
| `slate` | 青灰 | 常规（默认） | 安静的青灰，强调色是批改红 |
| `paper` | 暖纸 | 常规 | 米色纸面，墨色偏棕 |
| `mist` | 雾蓝 | 常规 | 偏冷的蓝灰 |
| `plain` | 素白 | 常规 | 不带色相的中性灰，接近 WPS |
| `dark` | 深色 | 常规 | 面板与工作台变暗，强调色提亮；阴影改为黑色、加深 |
| `noir` | 赤黑 | 风格 | 红黑白高反差，锐利、爽快 |
| `tide` | 月潮 | 风格 | 深海蓝与青色，灵动、柔和 |

常规主题只换基础色；风格主题还改造型、悬停与动效，规则全部限定在各自的 `:root[data-theme='…']` 之下，切回其他主题一切如常。
两套风格主题都是**原创**的视觉语言，不使用任何游戏的标志、字体、角色或素材（软件要分发给其他老师）。

## 3. 风格主题：赤黑（`noir`）

关键词：**锐利、爽快、躁动**。红、黑、白三色，直角与斜切。

| 部位 | 做法 |
|---|---|
| 底色 | 黑色工作台铺红色网点；面板深灰；标签栏整条红色 |
| 造型 | 一律直角；标题、主按钮、选中条、组标题用斜切色块（`--cut-right`、`--cut-both`） |
| 标题 | 拼贴字：每个字一块剪报纸片，底色（白、黑、红、旧报纸等七种）、字体（宋体、黑体、楷体）、角度、大小各异；悬停时纸片各自翻动 |
| 投影 | 不模糊的硬边投影，用压暗的深红 `--shadow-red`（`#8c1219`），弹窗遮罩是黑色 |
| 悬停条目 | 条目底下一红一白两块错开的不规则四边形，四个角各自连续游移（约 1.8 秒、2.3 秒一圈），文字变白色斜体；“删除”为黑底红边 |
| 按钮 | 悬停黑白反转并倾斜放大、带回弹；主按钮悬停时轻轻抖动；按下回正缩小 |
| 输入框 | 悬停白边加错开的深红硬边，聚焦时硬边变为正红 |
| 分段按钮 | 悬停抬起倾斜，选中时带旋转弹入 |
| 勾选框 | 倾斜方块，勾上变红 |
| 属性栏字段 | 直接放在属性栏里的字段（标题、内容、难度等）加框，字段名是压在框线上的红色斜切标签 |
| 滚动条 | 黑色轨道，红黑斜纹滑块，悬停黑白斜纹，拖动时纯白 |
| 浮层 | 白色粗边加深红硬边投影，带倾斜“甩”进来；对话框从歪到正 |
| 预览中右键的快捷窗口 | “战斗指令”式：各项以鼠标点下的位置为中心，分左右两列向四周散开——`QuickPopover` 把内容包在 `.quick-menu-body` 里（常规样式下 `display: contents` 不参与排版），主题把它排成“左列 / 中间留空 / 右列”的网格，弹出时量出这块空处的中心并对准鼠标位置（只在它确实是网格时才这样定位，关掉该动效就退回常规定位）。每项是一块歪着的黑色厚板（`::after`），身后叠一块更大、角度不同的红色厚板（`::before`），越往上下越往里收、越歪，排成扇形；字段名在上、用拼贴字（`Row` 通过 `StageContext` 得知在战斗菜单里），控件在下，控件文字固定浅色；标题横在最上（同样是黑板叠红板、白字）；动作按钮在最下，上移、下移是黑板叠红板，删除反过来是红板叠黑板。各项从中心向外甩出，悬停的那块回正放大、红板张开、黑板亮起白边。**大纲里右键打开的仍是紧凑的常规样式**（左侧空间小），区别在 `QuickPopover` 的 `stage`（加 `quick-menu--stage`） |
| 页面切换 | 一道较窄的斜幕（黑底、两侧 18px 深红边）沿左上→右下扫过，前面是旧页面、后面是新页面，全程一段缓入缓出位移，约 0.72 秒 |

## 4. 风格主题：月潮（`tide`）

关键词：**灵动、柔和、水**。深海蓝、青色、白色，细斜角与辉光。

| 部位 | 做法 |
|---|---|
| 底色 | 深海蓝渐变，右上方一团月光，很淡的水平细纹；面板与浮层半透明 |
| 造型 | 小圆角；当前标签与主按钮是青色平行四边形（`--cut-para`） |
| 标题 | 逐字从水中浮起（模糊、偏下 → 清晰），之后随水轻轻上下漂动，隔几个字带青色反光；大标题下有一道青色光带 |
| 悬停条目 | 边框加反色：白色斜切底从左侧铺开，文字反成深蓝斜体，青色边框，右上角错开一道细红边 |
| 选中条目 | 与悬停相反：深色底、青色边框、白字 |
| 按钮 | 悬停时一道白光从左掠到右，边框亮起青色辉光，微微上浮 |
| 输入框 | 悬停边框发亮，聚焦一圈青光 |
| 分段按钮 | 选中时一圈光波向外扩散 |
| 勾选框 | 菱形，悬停旋转，勾上发光 |
| 属性栏字段 | 加框，字段名与组标题是压在框线上的青色平行四边形标签 |
| 滚动条 | 深海轨道，青色渐变的细长滑块 |
| 浮层 | 从左侧水平滑入；对话框从水下浮上来（模糊、偏下 → 清晰）；导出卡片从右侧滑入 |
| 危险操作 | 保留暖红（`--keypoint`），不随强调色变青 |
| 页面切换 | 旧页面以底边为轴向后仰倒、下沉、淡出；浅青、亮蓝、深蓝三层纯色海水依次从上往下灌，下缘是舒缓的波浪，领头那层描白色亮线，几个空心水泡上浮；海水淡去后露出新页面，约 1.1 秒 |

## 5. 风格主题的动效开关

“设置… → 配色”中选了风格主题时，下面列出该主题可单独开关的动效（登记在 `shared/themes.ts` 的 `effects`）。
关掉的一项改用常规主题的效果，其余照旧。

| 主题 | 动效编号与名称 |
|---|---|
| 赤黑 | `wipe` 切换标签页时的斜幕、`collage` 剪报拼贴标题、`quad` 悬停条目下的游移四边形、`tilt` 按钮与选项悬停时倾斜抖动、`popin` 菜单与对话框倾斜甩入、`stage` 预览中右键的战斗指令式菜单 |
| 月潮 | `wipe` 切换标签页时海水灌入、`rise` 标题逐字浮起漂动、`invert` 悬停条目反色加边框、`sheen` 按钮悬停流光与上浮、`popin` 菜单滑入与对话框浮出 |

- 存在 settings.json 的 `themeEffectsOff`（主题 → 关掉的编号列表，读写时只保留登记过的）。主进程启动时把当前主题的那份
  放进地址参数 `fxoff`，首帧就不播放；`theme/theme.ts` 读回全部主题的设置，切换主题时把当前主题的列表写到根元素 `data-fx-off`。
- CSS 的做法：`stage` 这类新加的效果，规则直接写成 `:root[data-theme='noir']:not([data-fx-off~='stage']) …`；
  已有的效果在 `app.css` 末尾用 `:root[data-theme='…'][data-fx-off~='编号'] …` 换回常规样子（多一个属性选择器，特异性更高，
  必要时 `!important` 对 `!important`）。入场类的效果在 `@starting-style` 里写回常规的起始值。
- 过场（`wipe`）由 `TabTransition.tsx` 读 `data-fx-off` 决定是否播放；关掉后首页照常规主题淡入。
- 新增可开关的动效：在 `effects` 里登记，再在 CSS 里加对应的关闭规则；系统“减弱动态效果”仍优先，所有动效一律关闭。

## 6. 页面切换的过场（`TabTransition.tsx`）

只在赤黑、月潮两个主题下播放；减弱动态效果时不播放。其他主题只给首页做 0.2 秒淡入，编辑器页面不做动画（见第 8 节）。

1. **拍快照**：标签页一切换 React 就把旧页面换掉了，所以在换掉之前先复制一份旧页面的 DOM 盖在上面。时机靠布局副作用的
   清理函数：本组件排在内容区之前，React 提交时先执行它的清理函数、再移除旧内容。复制后去掉对话框、浮层、预览的隐藏测量区，
   屏幕外的页面只留空外框，并恢复各区域的滚动位置。
2. **快照自成一层**（`isolation: isolate`）：否则快照里带 `z-index` 的浮动图片、SVG 图形会显示在幕布上面。
3. **撤掉旧页面用透明度或裁切，不用 `visibility`**：子元素可以把 `visibility` 改回 `visible`。
4. **新页面不做动画**：它在幕布或海水底下先画好，幕布扫过或海水淡去时直接露出来。
5. **动画交给显卡合成**：幕布、每层海水都是独立的元素，动画加在元素本身的 `transform` / `opacity` 上（不放在 SVG 内部图形上，
   也不用整窗 `filter: blur`），新页面在主线程上排版时，过场照样流畅。
6. 新增带过场的主题：改 `TabTransition.tsx` 里的 `enabled()` 主题判断与 `TOTAL_MS`，样式写在该主题的规则里，并在 `effects` 里登记 `wipe`。

## 7. 加一套新主题

1. `shared/themes.ts` 的 `ThemeId` 与 `THEMES` 里登记（名称、色块颜色、窗口底色）。
2. `app.css` 里加 `:root[data-theme='新编号'] { … }`，只覆盖基础色；深色类主题加 `color-scheme: dark`，
   并把 `.formula-field` 加进“公式输入框保持白纸黑字”那条规则。
3. 风格主题的额外规则一律限定在该主题之下，集中写在文件末尾，并照顾减弱动态效果；希望用户能单独关掉的动效，按第 5 节登记并写关闭规则。
4. 切到新主题，把首页、编辑界面、属性栏、右键快捷窗口、各对话框、下拉框、导出卡片都看一遍；新增组件后也要在两套风格主题下各看一眼。

## 8. 界面上踩过的坑

- **打开或切换到教学案时预览“跳一下”**：预览的缩放比例原来在 ResizeObserver 回调里算，第一帧先按 100% 画出，回调后再放大，
  看起来就是打开后突然放大、卡一下。现在在布局副作用里同步算好再画（`Preview.tsx`），并给预览区 `scrollbar-gutter: stable`，
  页面排出来、滚动条出现时可用宽度不变，不会二次跳动。缩放变化小于 0.2% 时不更新，避免亚像素抖动反复重排。
- **切换到教学案卡顿**：几件吃力的事叠在一起——预览所有页面一次性绘制、整个编辑器做淡入位移动画、过场快照复制整个旧页面、
  海水动画在主线程上与排版抢时间。对应改法：`.page-frame` 加 `content-visibility: auto`（只画屏幕附近的页面）；
  编辑器页面不做进入动画；快照瘦身；过场动画交给显卡合成，去掉整窗模糊。
- **动画结束时“跳一下”**：对大块内容做 `filter: blur` 或 `scale` 动画，结束撤掉的那一刻文字从合成层换回正常绘制，看得出跳变。
  大块内容的进入动画只用透明度和位移。
- **菜单冒出横向滚动条**：悬停效果出现的一瞬间会略微伸出条目，可纵向滚动的菜单随之出现横向滚动条。`.menu-popup`、`.context-menu`
  设 `overflow-x: hidden`。
- **字段标题与控件挤在一行**：给 `.field-label` 设 `display: inline-block` 会让它和后面的控件排到同一行、互相重叠（窄窗口里尤其明显）。
  要让标题宽度贴合文字，用 `width: fit-content`，保持块级。
- **过场一开始黑屏、底部露一截**：幕布或水体的起点、终点都要完全在画面外（水体比画面高出一截、起点提到画面之上），
  否则第一帧就露出一条边，或灌到底时底部留缝。
- **幕布、海水的透出与闪烁**：见第 6 节第 2、3 条。整屏大面积亮色快速交替（早期赤黑的三层红白黑幕布）会晃眼，
  过场的颜色要与界面底色接近，靠一条细边体现。
- **`::-webkit-scrollbar` 不生效**：Chromium 121 起，只要元素设了标准的 `scrollbar-width` 或 `scrollbar-color`，
  `::-webkit-scrollbar` 就被忽略。风格主题自定义滚动条时先把这两个属性设回 `auto`。
- **悬停四边形的伪元素冲突**：赤黑、月潮的悬停效果用条目的 `::before` / `::after` 画在底下，新加入那组选择器的条目
  不能已经占用这两个伪元素。
- **拼贴字的用法**：只包短标题（`CollageText`），样式编号由文字算出，同一标题每次一样；不要用在长文本或会被截断的地方。
  读屏读隐藏的整段文字，拆开的字对读屏隐藏。
- **斜切按钮的焦点框**：`clip-path` 会裁掉外侧的焦点框，斜切的按钮把焦点框画在内侧（`outline-offset` 取负值）。
