导入题目与知识点 ​

软件支持从 Word / 组卷网文档、图片（AI 识图 / WorkBuddy） 与 墨案 导入题目或知识点，尽量保留原有公式、表格、插图和题号结构。

1. 从 Word 文档与组卷网导入 ​

  • 入口：首页点 从 Word 文档新建（或双击 .docx），或在编辑界面点 导入题目 ▾ → Word 文档…（追加到当前选中项之后）。
  • 组卷网文档：自动将题组整理为综合题并共用答案解析，识别短标题、配图、选项、小问与难度等级（0.7 以上 A、0.5～0.7 B、低于 0.5 C），自动清除“学校/姓名/系统分组”等干扰行。
  • 普通文档：使用“物理排版”样式按样式精确识别；其余文档按 1.、A.、【答案】、【解析】 等标记切分，保留 MathType / EQ 域 / Word 公式、形状示意图、表格与文字颜色。
  • 物理教学案预设：导入时自动将 【详解】 转为 【解析】 并统一解析为黑色，保留知识梳理中的红色、加粗与下划线，同时自动识别作业单。

2. 从图片导入（AI 识图 / WorkBuddy） ​

  1. 点击 导入题目 ▾ → 图片（交给 AI 识别）…，选择文件、拖入或按 Ctrl+V 粘贴截图。
  2. 软件在本地自动框选插图并按阅读顺序编号为 [图1]、[图2]（可拖动、改四角、删除或手拉新框自动收紧），默认同时开启 插图变清晰。
  3. 两种识别方式：
    • 通用 AI：点击 复制给 AI 的指令，连同图片发给 WorkBuddy、豆包、Kimi 等 AI，再将返回的代码块粘贴回右侧，底部会实时检查题数、公式与漏框后导入。
    • WorkBuddy 免粘贴：在首页 设置… → WorkBuddy 自动识别 → 连接 WorkBuddy（只需一次），之后在导入窗口点 交给 WorkBuddy 识别，到 WorkBuddy 里说一句 导入题目，结果会自动回填。

3. 从墨案迁移与导入知识点 ​

从墨案迁移教案 ​

  • 点击首页 从墨案导入…（或 文件 → 从墨案导入…）登录墨案账号（保留登录状态）。
  • 打开单篇教案会询问是否导入；进入文件夹后可通过窗口菜单 导入 → 导入当前文件夹的全部教案 批量迁移。
  • 迁移后默认使用 数学教学案 V1.0 预设，保存在 教学案库\墨案导入，完整保留题目、变式题（a. b. c.）、答案解析、LaTeX/MathML 公式、图片、作答留白、换页、审题与重点题标记，并自动拆出表格里的选择题选项。

导入知识点 ​

  • 点击工具栏 导入知识点 ▾（支持 Word 文档 或 图片）。
  • 以 一、…… 开头的内容识别为知识点分组，其下 1. 序号列表不会被误拆成题目。
