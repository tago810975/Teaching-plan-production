格式预设与自制模板 ​

软件通过 格式预设（preset.json） 与 Word 模板（template.docx） 控制导出文档的结构与页眉外观。

1. 两套内置通用格式预设 ​

在“新建教学案”“从 Word 文档新建”时可选择预设，或在首页 设置… 中指定“导入时默认格式预设”：

预设名称适用场景核心特点
教学案常规新授 / 复习课（通用）含大标题、栏目标题（知识梳理 / 例题精讲 / 课堂练习 / 课后练习 / 课堂总结）、题型分组与作业单；页眉加 (教案) / (学案)；导入时将 【详解】 转为 【解析】 并统一为黑色
题型整理单题题型突破小页册（通用）一份讲一道例题：例题、审题（灰底注释框）、解题（思维过程 / 书写过程 对照表）、易错提醒、题后归纳；题目不编号、默认 1.3 倍行距；学生版书写栏换为虚线格

自制模板的 preset.json 还支持 kind: "handbook"（知识点手册重点挖空默写）、自定义学科页眉以及 questionFields（审题与重点题默认开关）等扩展配置。

2. 自制与分享模板（三步完成） ​

内置模板只读，可复制一份在本地模板目录（默认为 文档\教学案\模板\，升级软件不会覆盖）中修改：

  1. 复制模板：首页进入 模板… → 选中接近的内置模板 → 点击 复制为新模板。
  2. 按需修改：
    • 改 preset.json：调整模板名、三级标题字体字号、栏目名、默认行距、审题/重点题开关、页眉文字与挖空规则等；
    • 改 template.docx / header/：替换学校 Logo、页眉电话、水印与页边距（需保留 占位符及原有样式名；不建议直接改正文/题目样式的字号缩进，以免预览与导出不一致）。
  3. 载入与分享：回到 模板… 点 重新载入 即可使用（有格式错误会显示中文提示）；点 导出为 zip 可发给其他老师用 导入模板… 直接安装。
