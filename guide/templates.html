格式预设与自制模板 ​

软件通过 格式预设（preset.json） 和 Word 模板（template.docx） 控制导出的版式结构与外观，既可以直接选用内置预设，也可以复制改造成自己学校或教研组的专属样式。

1. 四套内置格式预设 ​

在“新建教学案”“从 Word 文档新建”时可以切换预设，也可以在首页 设置… 中指定“导入时默认格式预设”：

预设名称适用场景核心特点
物理教学案 V1.0常规物理新授课 / 复习课教案学案包含大标题、栏目标题（知识梳理 / 例题精讲 / 课堂练习 / 课后练习 / 课堂总结）、题型分组与作业单模块；页眉自动带 (教案) / (学案) 后缀；导入时自动把 【详解】 转为 【解析】 并统一解析为黑色
物理知识点手册 V1.0知识清单、考前默写讲义结构精简，仅包含大标题与“一、二、三……”知识点；学生版自动把标为“重点”（红色加粗下划线）的文字、公式与表格内容挖空成横线，用于课堂默写；页眉不加 (教案) / (学案)
物理题型整理 V1.0单题母题突破、题型归纳小页册一份讲透一道母题：例题、审题（灰底注释框）、解题（思维过程 / 书写过程 对照表）、易错提醒、题后归纳；题目不编号，标题用黑体，默认 1.3 倍行距；学生版把对照表书写栏换为虚线格；预制模块自带整份骨架、注释框与续表
数学教学案 V1.0数学新授课 / 例题带变式教学案栏目为知识梳理 / 例题精讲 / 课堂练习 / 课堂总结 / 课后练习；难度分 A～E 五级；默认开启 审题 与 重点题 可选项；从墨案导入的教案默认使用此预设

2. 自制与分享模板 ​

内置模板为只读状态，不能直接修改，但你可以复制一份改造成自己的版本：

第一步：复制为新模板 ​

  1. 在首页左侧栏进入 模板… 对话框。
  2. 选中最接近你需求的内置模板，点击 复制为新模板。
  3. 软件会在你的模板目录（默认为 文档\教学案\模板\，随教学案库路径走）下创建一个新模板文件夹，包含 preset.json、template.docx、header/ 和说明文件 README.md。

第二步：自定义修改 ​

打开新建的模板文件夹，按需编辑：

  • 调整格式预设（preset.json）：可修改模板显示名称（name）、大标题/栏目标题/题型分组的字体与字号（headings）、常用栏目名称（sectionNames）、默认行距（lineSpacing）、是否开启审题/重点题（questionFields）、页眉文字与是否追加 (教案)/(学案) 后缀（header）、作业单字段（worksheet）或默写挖空规则（dictation）等。
  • 修改页眉与纸张（template.docx / header/）：可在 template.docx 中调整学校 Logo、页眉电话、水印与页面设置（务必保留正文占位符 及原有样式名称）。

关于修改样式字号的边界

目前只有三级标题（大标题、栏目标题、题型分组）的格式支持在 preset.json 中独立覆盖；正文、题目、选项等共用样式由软件内排版引擎统一绘制。因此不建议直接更改 template.docx 中正文和题目样式的字号缩进，以免出现预览与导出 Word 不一致。

第三步：重新载入与导出分享 ​

  1. 改好后回到首页 模板… 对话框，点击 重新载入，新建教学案时就能选到你的自制模板了（如果 JSON 字段或模板占位符有误，对话框会直接列出具体中文错误原因）。
  2. 想分享给教研组其他老师？在对话框中点击 导出为 zip 发给对方，对方在自己的软件里点 导入模板… 即可一键装上。
  3. 自制模板保存在教学案库里，升级软件版本时不会被覆盖。
