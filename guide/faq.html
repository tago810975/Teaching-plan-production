常见问题与主题设置 ​

1. 软件设置与配色主题 ​

在首页左侧栏点击 设置…，可配置 教学案库位置、导入默认格式预设、公式字母默认正斜体、默认导出知识点重点难点汇总、连接 WorkBuddy 以及 配色主题（预览 A4 纸面与导出 Word 始终保持白纸黑字，不受主题影响）：

主题名称类型视觉风格说明
青灰（默认）常规安静的青灰工作台，配“批改红”强调色
暖纸 / 雾蓝 / 素白 / 深色常规分别提供米色纸面、冷调蓝灰、中性素白与暗色面板
赤黑风格主题红黑白高反差、剪报拼贴标题、游移四边形悬停、斜幕切页与右键“战斗指令”式菜单
月潮风格主题深海蓝与青色辉光、逐字浮起标题、流光按钮与三层海水切页过场

选择“赤黑”或“月潮”后，下方可逐项开关动效；系统开启“减弱动态效果”时动画自动关闭。

2. 常用快捷键速查 ​

场景快捷键功能
首页文件列表Enter / F2 / Delete打开 / 重命名（同步 .tplan 文件名） / 删除到回收站
标签页管理Ctrl+Tab / Ctrl+W切换标签页 / 关闭当前标签页（鼠标中键也可关闭）
编辑界面Ctrl+E打开导出 Word 对话框

图片与表格Shift + 拖动 / Shift + 单击全部选项图一起缩放 / 连选多个单元格合并
大纲排序Esc取消当前拖拽排序

3. 常见问题 ​

  • 导出的 Word 其他老师能直接改吗？ 可以。导出为标准 .docx，题号与 【答案】 为 Word 自动编号，公式和表格为 Word 原生格式，无需安装本软件即可在 Word / WPS 中继续编辑。
  • .tplan 工程怎么备份或发给同事？.tplan 是单文件工程（内置题目、公式与全部插图），直接复制 .tplan 文件或备份整个教学案库目录即可。
  • 安装后首次打开被系统拦截？ Windows 遇 SmartScreen 提示点 更多信息 → 仍要运行；macOS 遇提示请打开 系统设置 → 隐私与安全性 → 仍要打开，详见 下载安装说明。
  • 墨案导入登录卡住或失败？ 在墨案窗口 页面 菜单尝试 强制刷新（忽略缓存） 或 清除登录状态与缓存并刷新；若导入异常，点 导入 → 保存诊断文件（已隐去登录凭证）以便排查。
