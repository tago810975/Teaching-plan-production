# 教学案制作（Teaching-plan-production）

导入题目文档、自动排版，一份工程同时导出教师版（教案）与学生版（学案）Word 文档的桌面软件。支持 Windows，后续移植 macOS。

> 接手开发（包括新开的 AI 对话）请先阅读 [`docs/开发交接.md`](docs/开发交接.md)：架构原则、数据模型纪律、
> 功能现状、待办事项、测试验证方法与协作约定都在里面。
> 制作新的格式预设或 Word 模板，请读 [`docs/模板制作指南.md`](docs/模板制作指南.md)。

## 开发环境

- Node.js 22 或更高版本
- Windows 10/11（macOS 亦可运行开发版）

```bash
npm install        # 安装依赖（首次会下载 Electron，约 100 MB）
npm run dev        # 启动开发版，修改界面代码后自动刷新
npm test           # 运行单元测试
npm run typecheck  # 类型检查
npm run dist:win   # 打包 Windows 安装程序，输出到 release/
```

## 常见问题

**启动时报错 `Failed to resolve import "xxx"`**

代码新增了依赖库，而本地还没有安装。每次 `git pull` 之后都执行一次 `npm install`（依赖没有变化时几秒钟就结束）。

**启动时报错 `Error: Electron uninstall`**

Electron 的主程序（约 100 MB）在 `npm install` 的最后一步从 GitHub 下载，网络不通时会静默失败。指定国内镜像后单独重新下载即可：

```bash
# Git Bash / MSYS2
export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
node node_modules/electron/install.js
```

```bat
:: 命令提示符（cmd）
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
node node_modules\electron\install.js
```

成功后 `node_modules/electron/dist/` 下会出现 `electron.exe`。

**PowerShell 提示“禁止运行脚本”**

改用命令提示符（cmd），或在 PowerShell 中执行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

## 使用说明

### 首页与文件

- 启动后进入首页（参照 WPS）。左侧栏：“新建教学案”“从 Word 文档新建”“打开”，“最近”“教学案库”
  （默认为“文档\\教学案”，可建子文件夹分类），以及本地的桌面、文档、下载与各磁盘；文件夹可逐级展开，
  点开后右侧列出其中的教学案与 Word 文档。
- 右键文件（或点“⋯”）：打开、导出 Word、重命名、在文件夹中显示、删除（移到回收站）；双击 Word 文档直接用它新建教学案。
  快捷键：Enter 打开、F2 重命名、Delete 删除。在软件之外删除或移动的文件，右键“从列表中移除”或点“清除失效项”。
- “新建教学案”只需输入名称与选择格式预设，文件立即创建在教学案库中，并带入模板的页眉（Logo、电话、水印）。
- 多个教学案：每个打开的教学案在顶部占一个标签页，点击切换（Ctrl+Tab / Ctrl+Shift+Tab），× 或鼠标中键关闭（Ctrl+W），
  可拖动调整顺序，“＋”新建。未保存的标签页名称前有圆点；关闭时询问是否保存。编辑页左上角“首页”回到首页而不关闭教学案。
- 首页的“题目”数按题号计，综合题中的每道小题都算一道。

### 编辑界面

- 三栏：左侧大纲、中间分页预览、右侧属性面板。左右两栏的宽度可拖动边界调整，双击边界恢复默认。
- 撤销与重做：顶栏 ↶ ↷，或 Ctrl+Z 撤销、Ctrl+Y（或 Ctrl+Shift+Z）重做，最多 200 步；同一处连续打字算一步。
- 点击定位：在预览中点击任意一行，右侧对应的输入框滚动到该段，光标停在点击位置附近。
- 快捷版式：在预览或左侧大纲中右键一道题（或知识点、综合题、标题），弹出小窗口：难度、选项排布、整题同页、题后留白、
  从新的一页开始、题号重新开始、综合题答案的位置、“移到”某道综合题，以及上移、下移（可连续点击）、删除。
  右键题图、插图弹出图片的小窗口：位置、宽度、前移后移、删除；右键选项中的图片可改宽度、一起缩放、统一大小。
- 大纲排序：按住一项约 0.3 秒即可拖动，松开放到蓝色插入线处；拖动时滚动鼠标滚轮可快速翻动，拖到边缘会自动滚动，
  按 Esc 取消。题目（含综合题中的小题）可以拖进、拖出综合题：拖到小题之间即放进那道综合题；拖到综合题末尾时，
  鼠标偏右放进综合题、偏左放在综合题后面（插入线缩进表示放进）。

### 导入

- 首页“从 Word 文档新建”，或编辑界面“导入 Word 题目”（插入到当前选中内容之后）。
- 使用“物理排版”样式的文档按样式精确识别；其他文档按“1.”题号、“A.”选项、“【答案】”“【解析】”等标记识别。
- 组卷网下载的题目可直接导入：题组（材料与几道小题）做成综合题，共用答案与解析；短标题、背景、配图、选项、小问都会识别；
  难度系数换算为难度等级（0.7 以上 A、0.5～0.7 B、低于 0.5 C）；“学校:___姓名:___”与“系统分组”等行会去掉。
- 导入保留公式（MathType、EQ 域、Word 公式）、形状示意图、表格（合并单元格、列宽、底纹）、加粗、文字颜色与字体（归入宋 / 黑 / 楷 / 仿宋）。
- **从墨案导入**：首页“从墨案导入…”（或菜单“文件 → 从墨案导入…”）打开墨案窗口，登录后打开要迁移的教案，软件会询问是否导入；
  也可进入教案所在的文件夹，用窗口菜单“导入 → 导入当前文件夹的全部教案”一次导入。生成的教学案（数学教学案 V1.0）保存在
  “教学案库\\墨案导入”，题目、变式题（a. b. c.）、答案、解析、公式、图片、留白、换页都会保留。登录状态会保留。
- 物理教学案预设：【详解】统一改为【解析】，解析文字统一为黑色；知识梳理中的红色、加粗、下划线保留；自动识别作业单。

### 题目与综合题

- 难度分 A ★ 简单、B ★★ 中等、C ★★★ 难，显示在题干开头（如【B】★★）和大纲中；“版式设置 → 难度显示”可选择显示方式。
- 综合题：标题（如“材料一”）+ 可选的背景材料与配图 + 若干小题（题号与全卷连续）。答案与解析可选
  “集中在最后”或“分到各小题”（在综合题的属性面板或右键快捷窗口中切换，按题号拆开或合并，可撤销）。
- 小题跨综合题移动：小题上移到第一道之前、下移到最后一道之后会移出综合题；独立的题目紧挨着综合题时上移、下移会移进去；
  也可用快捷窗口的“移到”或在大纲中拖动。答案已分到各小题时，答案与解析跟着题目走。
- 作业单：“添加”菜单的预制模块中插入——从新的一页开始，大标题、“姓名 / 教室 / 正确率”栏，其后的题目从 1 重新编号。
- 大标题、栏目标题、题型分组：属性面板“版式”中可勾选“从新的一页开始”与“之后的题号从 1 重新开始”。

### 知识点与表格

- 知识点：知识梳理按“一、二、三……”标题分组为知识点（标题、内容、插图），可设置留白、跨页与换页；
  每段可设置段后空行、从此段换页，也可从某段拆分出新的知识点。
- 重点：编辑知识点时，格式工具栏最前面的“重点”按钮把选中的文字或公式设为红色加粗下划线，再按一次取消。
  知识点手册的学生版会把这些内容挖空成横线，用于默写。
- 表格：在输入框下方点“插入表格”新建、“编辑表格”修改：插入、删除行列；按住 Shift 点另一个单元格选中一片后“合并单元格”，
  光标在合并单元格中时“拆分单元格”；按厘米设置列宽，或“平均分布”“自动”；编辑器中有格式工具（含“重点”）与撤销重做。
  也可以在预览中直接拖动表格的竖线调整列宽。输入框中表格显示为 ⟦表格N⟧，删掉它即删除表格。

### 图片

- 题目的图可放在题干下方、题干右侧、题干下方位于选项 / 小问右侧、某个小问下方、全部题目文字下方，或自由位置；
  知识点的插图可放在某段之后、某段右侧或自由位置。选中题目或知识点后，在预览中拖动图片右下角可等比缩放；
  右侧的图可上下拖动，自由位置的图可任意拖动，文字会绕开图片。
- 选项是图片的选择题：拖动某个选项图片的右下角只缩放这一张，按住 Shift 全部一起缩放；属性面板“选项图片”分组中可逐张设置宽度、
  全部缩小或放大 10%、以某个选项为准统一大小。图片变小后，选项会自动改排为每行 2 项或 4 项。

### 文字格式与公式

- 属性面板顶部的 B / I / U（或 Ctrl+B / I / U）给输入框中选中的文字加粗、倾斜、加下划线，再按一次取消；
  “红 / 黑 / 蓝”设置颜色（黑＝恢复默认）。选中公式标记 ⟦公式N⟧ 时可给公式加粗、加下划线、设颜色。
- 在预览中直接选中文字（或公式），上方出现工具条，同样可以加粗、倾斜、下划线、设为重点、改颜色。
- 字体：各输入框标题旁可选字体（随样式 / 宋体 / 黑体 / 楷体 / 仿宋），预览与导出一致。
- 公式：在预览中点击公式即可可视化编辑（含模板按钮与数学键盘）；“插入公式”在光标处插入新公式。
  从 Word 导入的公式若未修改，导出时原样保留。

### 版式

- 行距：版式设置中“行距”一组，标题、题目（含综合题、答案与解析）、知识点、正文段落分别设置倍数；默认值来自格式预设
  （物理题型整理为 1.3 倍，其余为单倍），可一键恢复。
- 版式设置（大纲顶部）：教案、学案分别设置每道题是否整题同页（教案默认允许跨页以节省纸张，学案默认整题同页），
  难度显示方式，选项位置（选择间距方案或修改各列从第几个字开始，可“另存为方案”供所有教学案使用）。
- 单道题可在“版式”中另行设置整题同页、选项排布、留白、从新的一页开始、本题单独的选项位置。

### 格式预设与模板

- 新建教学案、从 Word 文档新建时选择格式预设；首页可设置“导入时默认格式预设”：
  - “物理教学案 V1.0”：大标题、栏目标题（知识梳理 / 例题精讲 / 课堂练习 / 课后练习 / 课堂总结）、题型分组、作业单等。
  - “物理知识点手册 V1.0”：只有大标题与“一、二、三……”知识点；学生版把红色加粗的重点（文字、公式、表格中的）挖空成横线；
    页眉不加“(教案)”“(学案)”。
  - “物理题型整理 V1.0”：一份讲一道母题——例题、审题（灰底注释框）、解题（“思维过程 / 书写过程”对照表）、易错提醒、
    题后归纳；题目不编号，标题用黑体，页眉不加“(教案)”“(学案)”。“添加”菜单的预制模块中有整份骨架、注释框、对照表与续表。
    学生版把对照表的书写栏换成虚线格（在表格编辑器中设“当前单元格在学生版换成书写横线 N 行”）。
    正文段落可在属性面板勾选“灰色底纹（注释框）”。
- **自制模板**：首页“模板…”。内置模板不能修改；点“复制为新模板”后，在模板文件夹（“文档\教学案\模板”，随教学案库）中修改
  preset.json（名称、标题格式、行距、栏目名等）与 template.docx，再点“重新载入”，新建教学案时就能选它。
  可以把模板导出为 zip 发给其他老师，对方用“导入模板…”装上。没能载入的模板会在对话框中列出原因。
- 制作新的格式预设与 Word 模板，见 [`docs/模板制作指南.md`](docs/模板制作指南.md)。

### 导出

- 编辑界面“导出 Word”（Ctrl+E），可同时导出教案与学案，文件名为“(T)名称.docx”（教师版）与“(S)名称.docx”（学生版）。
  首页右键教学案也可直接导出。
- 导出的文档沿用模板样式，题号、小问号、【答案】等由 Word 自动编号生成，公式为 Word 原生公式，表格为 Word 表格，
  其他老师可以直接编辑。

## 目录结构

```
src/
  core/        纯逻辑，不依赖界面，可单独测试
    model/         数据模型、校验、工厂函数
    project-file/  工程文件 .tplan 的读写
    document/      排版规则（build.ts）、文档中间表示（ir.ts）、样式表、分页
    presets/       格式预设（每个预设一个 JSON：物理教学案 V1.0、物理知识点手册 V1.0、物理题型整理 V1.0）
    import/        Word 导入（读取、识别、组卷网预处理、按预设整理）
    export/        Word 导出
    sample/        演示内容
  shared/      主进程与界面之间的通信接口
  main/        Electron 主进程：窗口、菜单、文件读写
  preload/     向界面暴露受限的 API
  renderer/    界面（React）：首页、标签页、大纲、分页预览、属性面板
resources/     Word 模板（templates/<模板 ID>/）
scripts/       从示例文档生成 Word 模板的脚本
test/          单元测试（test/renderer 为界面层）
reference/     用户提供的示例文档及其分析（测试依赖）
docs/          开发交接、模板制作指南、技术选型
```

## 核心约定

**预览与导出一致**：工程数据先由 `core/document/build.ts` 生成文档中间表示（DocIR），预览和 Word 导出都只读取 DocIR。所有排版规则（题号、选项分列、教师版/学生版取舍、留白、防跨页）只能写在 `build.ts` 中。

**工程文件**：`.tplan` 是 ZIP 容器，改扩展名为 `.zip` 即可解压查看。格式说明见 `src/core/project-file/format.ts`。

**依赖版本**：全部固定为确切版本，且只选用发布满两周的版本。
