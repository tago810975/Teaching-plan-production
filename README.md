# 教学案制作（Teaching-plan-production）

导入题目文档、自动排版，一份工程同时导出教师版（教案）与学生版（学案）Word 文档的桌面软件。支持 Windows，后续移植 macOS。

> 接手开发（包括新开的 AI 对话）请先阅读 [`docs/开发交接.md`](docs/开发交接.md)：架构原则、数据模型纪律、
> 功能现状、待办事项、测试验证方法与协作约定都在里面。

## 开发环境

- Node.js 22 或更高版本
- Windows 10/11（macOS 亦可运行开发版）

```bash
npm install        # 安装依赖（首次会下载 Electron，约 100 MB）
npm run dev        # 启动开发版，修改界面代码后自动刷新
npm test           # 运行单元测试
npm run typecheck  # 类型检查
npm run dist:win   # 打包 Windows 安装程序，输出到 release/
```

## 常见问题

**启动时报错 `Failed to resolve import "xxx"`**

代码新增了依赖库，而本地还没有安装。每次 `git pull` 之后都执行一次 `npm install`（依赖没有变化时几秒钟就结束）。

**启动时报错 `Error: Electron uninstall`**

Electron 的主程序（约 100 MB）在 `npm install` 的最后一步从 GitHub 下载，网络不通时会静默失败。指定国内镜像后单独重新下载即可：

```bash
# Git Bash / MSYS2
export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
node node_modules/electron/install.js
```

```bat
:: 命令提示符（cmd）
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
node node_modules\electron\install.js
```

成功后 `node_modules/electron/dist/` 下会出现 `electron.exe`。

**PowerShell 提示“禁止运行脚本”**

改用命令提示符（cmd），或在 PowerShell 中执行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

## 使用说明

- 首页：左侧栏有“新建教学案”“从 Word 文档新建”“打开”，以及“最近”“教学案库”和本地的桌面、文档、下载与各磁盘，
  文件夹可以展开，点开后右侧列出其中的教学案和 Word 文档。右键文件（或点“⋯”）可以打开、导出 Word、重命名、
  在文件夹中显示、删除（移到回收站）；双击 Word 文档可以直接用它新建教学案。快捷键：Enter 打开、F2 重命名、Delete 删除。
- 多个教学案：像 WPS 一样，每个打开的教学案在顶部占一个标签页，点击切换（Ctrl+Tab / Ctrl+Shift+Tab），
  × 或鼠标中键关闭（Ctrl+W），可拖动调整顺序，“＋”新建。未保存的标签页名称前有圆点；关闭时会询问是否保存。
- 撤销与重做：编辑页顶栏的 ↶ ↷ 按钮，或 Ctrl+Z 撤销、Ctrl+Y（或 Ctrl+Shift+Z）重做，最多 200 步；
  在同一处连续打字算一步。撤销时会选中改动所在的内容。

- 启动后进入首页，列出“教学案库”（默认为“文档\教学案”）中的全部教学案，以及最近打开过的其他位置的教学案。
- “新建教学案”只需输入名称，文件立即创建在教学案库中，并自动带入模板的页眉（Logo、电话、水印）。
- 教学案库可以建子文件夹分类管理（最多两层），首页会一并列出。
- 编辑时点击左上角“首页”或按 Ctrl+W 返回首页。
- 导入：首页“从 Word 文档新建”，或编辑界面“导入 Word 题目”（插入到当前选中内容之后）。
  使用“物理排版”样式的文档按样式精确识别；其他文档按“1.”题号、“A.”选项、“【答案】”“【解析】”等标记识别。
- 公式：在预览中点击任意公式即可可视化编辑（含模板按钮与数学键盘）；属性面板中“插入公式”在光标处插入新公式。
  从 Word 导入的公式打开后若未修改，导出时原样保留。
- 点击定位：在预览中点击任意一行，右侧对应的输入框会滚动到该段，光标停在点击的位置附近。
- 综合题：标题（如“材料一”）+ 可选的背景材料与配图 + 若干小题（题号与全卷连续）+ 共用的答案与详解。
  大纲中小题缩进列在综合题之下，点击即可单独编辑；拖动综合题时小题随之移动。
- 知识点：知识梳理按“一、二、三……”标题分组为知识点（标题、内容、插图），与题目一样可设置留白、跨页与换页；
  “添加”菜单中也可以新建知识点。
- 图片位置：题目的图可放在题干下方、题干右侧、题干下方位于选项/小问右侧、某个小问下方、全部题目文字下方，
  或自由位置；知识点的插图可放在某段之后、某段右侧或自由位置。选中题目或知识点后，在预览中拖动图片右下角
  可等比缩放；右侧的图可上下拖动，自由位置的图可任意拖动，文字会绕开图片排布。
- 选项是图片的选择题：选中题目后，在预览中拖动某个选项图片的右下角，只缩放这一张；按住 Shift 拖动，全部选项图片
  按同一比例一起缩放。属性面板“选项图片”分组中可以逐张设置宽度、全部缩小或放大 10%、以某个选项为准统一大小
  （每张图保持自身宽高比，不会变形），也可以勾选“拖动时全部一起缩放”，此时按住 Shift 只缩放一张。
  图片变小后，选项会自动改排为每行 2 项或 4 项。
- 首页的“题目”数按题号计，综合题中的每道小题都算一道。
- 字体：题干、选项、小问、答案、详解、综合题背景、知识点内容的标题旁可选字体（随样式 / 宋体 / 黑体 / 楷体 / 仿宋），
  作用于整个输入框。预览与导出的 Word 使用相同字体；从 Word 导入时会保留加粗、文字颜色与字体（归入上述四类）。
- 格式预设：新建教学案、从 Word 文档新建时选择格式预设：
  - “物理教学案 V1.0”：大标题、栏目标题（知识梳理 / 例题精讲 / 课堂练习 / 课后练习）、题型分组、作业单等。
  - “物理知识点手册 V1.0”：只有大标题与“一、二、三……”知识点；学生版把红色加粗的重点（文字和公式）挖空成横线，
    用于默写；页眉不加“(教案)”“(学案)”。
  首页可以设置“导入时默认格式预设”。
- 表格：从 Word 导入时保留表格（合并单元格、列宽、底纹、单元格中的公式与图片），预览与导出均为表格。
  在输入框下方点“插入表格”新建，点“编辑表格”修改：插入、删除行列（有合并单元格时也可以）；按厘米设置列宽，
  或“平均分布”“自动”（平分版心）；按住 Shift 点另一个单元格选中一片后
  “合并单元格”，光标在合并单元格中时“拆分单元格”；编辑器中有格式工具（含“重点”，学生版同样挖空），
  可用 Ctrl+Z / Ctrl+Y 撤销重做。输入框中表格显示为 ⟦表格N⟧，删掉它即删除表格。
- 在预览中改格式：直接在预览中选中文字（或公式），上方会出现工具条，可加粗、倾斜、下划线、设为重点、改颜色，
  可用 Ctrl+Z 撤销。
- 首页：在本软件之外删除或移动的文件，可右键“从列表中移除”，或点“最近”旁的“清除失效项”。
- 导出 Word：文件名为“(T)名称.docx”（教师版）与“(S)名称.docx”（学生版）。
- 作业单：“添加”菜单的预制模块中可插入作业单——从新的一页开始，大标题、“姓名 / 教室 / 正确率”栏，
  其后的题目从 1 重新编号。导入 Word 时也会自动识别作业单。
- 难度：题目的难度分 A ★ 简单、B ★★ 中等、C ★★★ 难，显示在题干开头（如【B】★★）和左侧大纲中。
  “版式设置 → 难度显示”可选择题干中显示等级和星级、只显示等级、只显示星级或不显示。
- 导入时【详解】统一改为【解析】，解析文字统一为黑色；知识梳理中的红色、加粗、下划线保留。
- 文字格式：属性面板顶部的 B / I / U 按钮（或 Ctrl+B / Ctrl+I / Ctrl+U）给文本框中选中的文字加粗、倾斜、加下划线，
  再按一次取消；“红 / 黑 / 蓝”按钮设置文字颜色（黑＝恢复默认）。选中公式标记 ⟦公式N⟧ 时可给公式加粗、加下划线、
  设颜色（公式不倾斜；公式的下划线是整个公式下方一条平直的横线，分式画在分母下方）。
- 重点：编辑知识点时，格式工具栏最前面有“重点”按钮，一次把选中的文字或公式设为红色加粗下划线，再按一次取消。
  这些是需要学生记忆的内容，以后做默写单时会挖空。
- 选项位置：“版式设置”中选择间距方案（“默认”为四列等宽铺满整栏），或直接修改各列从第几个字开始，
  调好后可“另存为方案”并命名，所有教学案都能选用；单道题可在“版式”中勾选“本题单独设置”。
- 知识点的段落设置：每段可设置段后空行、从此段换页，也可从某段拆分出新的知识点。
- 大纲排序：在大纲中按住一项约 0.3 秒即可拖动，松开放到蓝色插入线处；拖动时滚动鼠标滚轮可快速翻动大纲，
  拖到大纲上下边缘会自动滚动，按 Esc 取消。
- 左侧大纲栏与右侧属性栏的宽度可调：鼠标移到边界上按住拖动；双击边界恢复默认宽度。调整后的宽度会被记住。
- 版式设置（大纲顶部）：教案、学案分别设置每道题是否整题同页。教案默认允许跨页以节省纸张，
  学案默认整题同页；单道题可在“版式”中另行设置。
- 导出：编辑界面“导出 Word”（Ctrl+E），可同时导出教案与学案。导出的文档沿用模板样式，
  题号、小问号、【答案】等由 Word 自动编号生成，公式为 Word 原生公式，其他老师可以直接编辑。

## 目录结构

```
src/
  core/        纯逻辑，不依赖界面，可单独测试
    model/         数据模型、校验、工厂函数
    project-file/  工程文件 .tplan 的读写
    document/      排版规则（build.ts）、文档中间表示（ir.ts）、样式表、分页
    presets/       格式预设（每个预设一个 JSON，如物理教学案 V1.0）
    import/        Word 导入（读取、识别、按预设整理）
    export/        Word 导出
    sample/        演示内容
  shared/      主进程与界面之间的通信接口
  main/        Electron 主进程：窗口、菜单、文件读写
  preload/     向界面暴露受限的 API
  renderer/    界面（React）：大纲、分页预览、属性面板
test/          单元测试
reference/     参考样例教学案及其分析
docs/          设计文档（技术选型等）
```

## 核心约定

**预览与导出一致**：工程数据先由 `core/document/build.ts` 生成文档中间表示（DocIR），预览和 Word 导出都只读取 DocIR。所有排版规则（题号、选项分列、教师版/学生版取舍、留白、防跨页）只能写在 `build.ts` 中。

**工程文件**：`.tplan` 是 ZIP 容器，改扩展名为 `.zip` 即可解压查看。格式说明见 `src/core/project-file/format.ts`。

**依赖版本**：全部固定为确切版本，且只选用发布满两周的版本。
