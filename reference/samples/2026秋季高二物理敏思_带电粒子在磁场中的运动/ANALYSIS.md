# 样例分析：2026 秋季高二物理敏思 · 带电粒子在磁场中的运动

教师版（T），37 页（LibreOffice 渲染），31 道题。与《动态圆专题》不同，这份文档来自题库，
公式与插图的存储方式更杂，用于检验导入的兼容性。

| 内容 | 数量 | 软件中的处理 |
|---|---|---|
| Word 原生公式（OMML） | 109 | 原样保留 |
| MathType 公式（Equation.DSMT4，MTEF 5） | 235 | 解析为 LaTeX，可编辑；导出为 Word 公式 |
| EQ 域公式（`eq \f(…)`、`eq \o\al(…)` 等） | 23 | 解析为 LaTeX |
| 形状绘制的示意图（wpg 组合） | 3 | 渲染为 SVG 图片，导出时转为 PNG |
| PNG 图片 | 57 | 原样保留 |

要点：

- MathType 公式的 OLE 对象中，“Equation Native”流保存 MTEF 数据，另附 WMF 预览图。
  其中 9 个公式在 MathType 中用 LaTeX 输入，MTEF 中多一条保存 LaTeX 源码的扩展记录（编号 102）。
- EQ 域 `\o\al(2,1)` 用于同位素记号左侧的质量数与电荷数（如 ²₁H）。
- 示意图由矩形、椭圆、带箭头的直线、`mathMultiply`（磁场“×”）、自定义路径（圆弧）
  与文本框标注组成；另一幅为同一张图片的两种裁剪并排组合。
  每幅图同时带有 VML 旧格式备份（`mc:Fallback`），导入时优先使用可渲染的新格式。
