# 样张：知识点重点难点汇总（题目要点文档）

`样张_T_带电粒子在磁场中的运动_知识点重点难点.docx`：用户提供的样张（原文件名“(T)10-2026秋季高二物理敏思_带电粒子在磁场中的运动(知识点重点难点).docx”）。
程序中对应 `src/core/document/points.ts`（`buildPointsDocument`），导出对话框中的“知识点重点难点汇总”。

## 结构（64 段，没有图片、公式、表格、页眉）

- 标题 1：“(T)<名称> 知识点重点难点汇总”
- 标题 2：栏目（例题精讲、课堂练习、课后练习）
- 每道题：一行“第N题”（全卷题号），其后【知识点】a、b；有的还有【重点】…、【难点】…
- 课堂练习下分标题 3“【重点题】”“【难点题】”两组，**只列出这两类题**（第 15、16、17、19、20 题没有出现）；
  其中第 22 题没有【重点】文字也在【重点题】组——“重点题”是题目的标记（`question.important`）
- 例题精讲、课后练习：列出全部题

## 程序中的规则

- 栏目：栏目标题、作业单各算一个；第一个栏目之前的题不加栏目标题
- 重点题：标记为重点题（题目可选项打开时）或写了【重点】；难点题：写了【难点】（且不是重点题）
- 栏目中有重点题或难点题时，只列这两类并分组；否则列出所有写了要点（知识点、重点、难点、审题）的题
- 审题：题目可选项打开时列出【审题】
- 题号取自教案的排版结果（与导出的教案一致）；样式用模板的大标题、栏目标题、题型分组、正文，页眉与教案相同
- 文件名“(T)名称(知识点重点难点).docx”；导出对话框中默认不勾选，首页“设置”中可改为默认勾选
