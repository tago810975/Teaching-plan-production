# 示例：物理题型整理（单题小页册）——放缩圆 母题01

对应格式预设：**物理题型整理 V1.0**（`src/core/presets/physics-typesummary-v1.json`）。

与其他示例不同，这份样张**不是 Word 文档**，而是用 LaTeX（xelatex + 自写的 `modi-handout.cls` / `modi-blocks.sty`）
编译出的 PDF：同一份 `.tex` 以 `student` / `teacher` 两个类选项各编译一次，得到学生版与教师版。
本软件按它的版式做了预设与预制模块，并用 `test/fixtures/type-summary-sample.ts` 把这道母题完整重搭了一遍。

| 文件 | 说明 |
|---|---|
| `原始素材_放缩圆.docx` | 题库原文：题型方法（适用条件、轨迹特点、临界条件）+ 一道多选题 + 答案、知识点、【详解】【点睛】 |
| `教案_T_放缩圆.pdf` | 教师版（4 页），由 `tex/mag-scalecircle-01.tex` 以 `teacher` 选项编译 |
| `学案_S_放缩圆.pdf` | 学生版（4 页），同一份 tex 以 `student` 选项编译 |
| `tex/` | 样张源码：`modi-handout.cls`（页面、页眉页脚、水印、字体）、`modi-blocks.sty`（内容组件）、`.tex`、`assets/` |
| `题目内容/` | 从原始素材整理出的文字底稿 `母题01.md` 与配图 |
| `示例_放缩圆母题01.tplan` | 用本软件重搭的同一道母题（由 `TYPE_SUMMARY_OUT=<目录> npx vitest run test/type-summary.test.ts` 生成），可直接打开查看 |

## 1. 版式（取自 cls / sty）

- A4，左右边距 36pt（约 1.27 cm），正文五号（10.5pt）宋体，行距 1.4 倍，首行缩进 1.5 字；西文与公式为 New Computer Modern。
- 页眉：左上 Logo，其下“墨帝教育高中物理”；中间电话；右侧章节（如“选修二 磁场 磁场力 带电粒子圆周运动”）。
  **不加“(教案)”“(学案)”**。页脚“第 X 页，共 Y 页”。整页斜向水印“墨帝教研专用内部资料”。
- 颜色：深蓝 `1F4E79`（表头、表格线）、浅蓝 `F2F7FC`（思维过程栏）、米色 `FDF8F2`（书写过程栏）、浅灰 `F2F2F2`（注释框）。

## 2. 结构（一份只讲一道母题，题目不编号）

| 顺序 | tex 组件 | 内容 | 教师版 / 学生版 |
|---|---|---|---|
| 1 | `\moditypetitle` | 大标题：题型名与适用条件，“放缩圆法：速度方向一定，大小不同”（黑体约 17pt 居中） | 相同 |
| 2 | `\modisectionhead` | 段落小标题：例题 / 审题：…… / 解题：…… / 题后归纳（黑体约 14pt） | 相同 |
| 3 | `modistem` + `\modinote` | 题干，需细读的条件后加上标圈号 ①②③④ | 相同 |
| 4 | `\modifigure` | 题图居中 | 相同 |
| 5 | `\modioption` | 选项 A.～D. 每行一项 | 相同 |
| 6 | `modinotes` + `\noteline` | 审题注释框：浅灰底，①②③④ 对应题干中的圈号，逐条把“文字描述”转成物理条件 | 相同 |
| 7 | `modisummary` | “审题总结：本题将包含”+（1）（2）……「认题型」「定不变量」…… | 相同 |
| 8 | `modicmp` / `modicmpcont` | “思维过程 / 书写过程”对照表（左 53%、右 47%），续表无表头 | **教师版右栏是规范书写，学生版右栏是虚线格** |
| 9 | `modistem` | 易错提醒 ①②③④ | 相同 |
| 10 | `modistem`、`tblr` | 题后归纳：方法三步、原理、方法图、对照小表、拓展思考 | 相同 |

**教师版与学生版的唯一区别**是对照表的书写栏（`\cmpwrite[行数]{内容}`）：学生版画 N 行浅蓝虚线。
样张中没有【答案】【解析】区，答案写在书写栏的最后（“故选 BC”）。

## 3. 程序中的处理

不新增块类型，用已有的块拼出各部分（`src/core/model/type-summary.ts`）：

| 样张 | 软件中 |
|---|---|
| 大标题 / 段落小标题 | 大标题、栏目标题（预设中为黑体；四个栏目名是 `sectionNames`） |
| 题干、题图、选项 | 题目块。预设 `numberQuestions: false`：不显示题号，首行缩进两字，导出时写 `numId 0` 取消样式的编号 |
| 圈号 ①② | 上标文字 |
| 审题注释框 | 正文段落块 + 整块浅灰底纹（`paragraph.shaded`，属性面板“灰色底纹（注释框）”） |
| 对照表 | 正文段落块中的表格：深蓝表头（白字黑体）、左栏浅蓝、右栏米色、蓝色边框、顶端对齐；右栏单元格 `studentLines`（表格编辑器“当前单元格在学生版换成书写横线 N 行”），学生版由 `build.ts` 的 `applyStudentLines` 换成虚线格；Word 中行不跨页、表头在续页重复 |
| 易错提醒、题后归纳 | 正文段落 / 知识点（加粗小标题） |

“添加”菜单的预制模块：整份骨架、审题注释框、对照表、续表（无表头），以及四个栏目标题。

## 4. 与样张的差别（已知）

- 正文行距：模板“物理排版 正文”是单倍行距，样张是 1.4 倍；正文字体样式目前不能由预设覆盖（见模板制作指南第 1 节）。
- 编号条目（（1）……、①……）没有悬挂缩进，续行顶格。
- 水印、页脚沿用 `physics-default` 模板（页脚“第 X 页 共 Y 页”）。
- 导入：原始素材 docx 可按教学案规则导入题目；审题、思维过程等是老师新写的内容，不能从原始素材自动生成。
