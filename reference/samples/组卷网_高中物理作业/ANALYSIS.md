# 示例：组卷网（zujuan.xkw.com）下载的题目

`组卷网_2026年11月6日高中物理作业.docx`：用于“导入 Word 题目”“从 Word 文档新建”（物理教学案预设）。
导入时识别为组卷网格式后，先由 `src/core/import/zujuan.ts` 预处理，再交给通用识别器。

## 与我们自己排版的教学案的区别

- **没有段落样式**：418 段全是默认格式；没有表格、没有自动编号。公式全是 OMML（1020 个），图片 56 张。
- 第一段是居中的试卷名（前面有两个小图标），第二段是“学校:___姓名：___班级：___考号：___”。
- “一、系统分组_加入顺序”是组卷网自动生成的分组名，没有意义。
- **题目以“题组”组织**，题号全卷连续：

```
[短标题，如“艺术体操”“摆动”“光的性质”（可无）]
[背景材料、配图（可无）]
N．小题……（选择题的选项另起段落，如“A．增大B．减小C．保持不变”“A．[图]B．[图]”；小问“（1）…”）
（空段落）
【答案】N．…    N+1．…            ← 一组共用一段，按题号分开；可能跨段（公式另起一段）
【难度】0.61                       ← 难度系数 0～1，越大越容易
【知识点】A、B、C
【详解】N．……（或【解析】）         ← 按题号分开，其中还有“[1]”“（1）”“故选A。”
```

- **上一组的解析与下一组的短标题、背景之间没有空行**，只能靠内容区分。
- 只有一道题、没有背景的组（第 28 题），答案不带题号：“【答案】（1）1.570 …”。

## 程序中的处理（zujuan.ts）

1. 去掉“学校:___”与“系统分组”行；“一、单选题”这类题型分组改为题型分组标题；第一段居中文字作为大标题。
2. 题号依次递增的“N．”才是新题（解析中的“N．”是已出现过的题号）；【答案】之前的小题为一组。
3. 每组的开头：从第一道小题往回，把短标题（≤12 字、无句读）、背景、配图划给本组；遇到解析的样子
   （以“故选”“解得”“[1]”“（1）”等开头、含公式、【…】标签）就停。
4. 有背景、标题，或两道以上小题的组插入“题组开始”标记 → 识别器新建综合题（共用答案与解析）；
   答案区中的段落加标记，其中“N．”开头的不再当作新题。
5. 【难度】换算为难度等级：0.7 以上 A（简单），0.5～0.7 B，低于 0.5 C（难）。
6. 整组共用的【知识点】留在综合题共用解析的开头（只显示一次，与原文一致）。
