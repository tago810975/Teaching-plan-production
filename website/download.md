## 系统要求

| 平台 | 支持环境 | 安装包格式 |
|---|---|---|
| **Windows** | Windows 10 / Windows 11（64 位） | `.exe` 安装向导（支持自定义安装目录） |
| **macOS** | macOS（Apple Silicon `arm64` / Intel `x64`） | `.dmg` 镜像包 |

## 安装注意事项

### Windows 安装说明

1. 运行下载得到的 `TeachingPlan-<版本号>-Windows-setup.exe`。
2. 如系统弹出 **Windows Defender SmartScreen**“Windows 已保护你的电脑”提示，点击 **更多信息 → 仍要运行** 即可正常安装（开源独立软件未购买商业签名证书）。
3. 安装向导过程中会要求选择 **教学案库** 的存放目录（默认为 `文档\教学案`），用于集中存放你的 `.tplan` 工程文件与自制模板。

### macOS 安装说明

1. 根据 Mac 芯片型号选择对应安装包：M 系列芯片选 `Mac-arm64.dmg`，Intel 芯片选 `Mac-x64.dmg`。
2. 将应用拖入 **应用程序（Applications）** 文件夹。
3. 由于当前尚未配置 Apple 开发者签名与公证，**首次打开**时若提示“无法验证开发者”或“来自身份不明的开发者”，请打开 **系统设置 → 隐私与安全性**，在下方点击 **仍要打开**。

::: tip 数据安全提示
软件更新时直接下载新版本安装包覆盖安装即可，你保存在「教学案库」中的 `.tplan` 工程文件、Word 文档和自制模板都不会被覆盖或删除。
:::
