# 插图与图像处理

针对老师日常最常遇到的试卷截图发灰、插图与文字混排、扫描图模糊以及图片选项对齐问题，软件内置了全套本地插图定位与图像增强工具。

## 1. 插图位置与预览交互

### 灵活的排版位置

- **题目的图**：支持放在 `题干下方`、`题干下方（居中）`、`题干右侧`、`题干下方位于选项 / 小问右侧`、`某个小问下方`、`全部题目文字下方` 或 `自由位置`。当选择题右侧有图时，每行 2 项或 4 项的选项会自动根据图片宽度调整间距并与图片同行排列。
- **知识点插图 / 答案插图 / 解析插图**：支持 `某段之后`、`某段之后（居中）`、`某段右侧` 或 `自由位置`。其中答案插图与解析插图在题目属性栏 **仅教师版** 页添加，只出现在教师版中。
- **独立成段图片的转换**：从网页或某些文档粘贴进来、在正文中单独成段的图片，属性面板会给出提示，点击 **转为插图** 即可纳入插图栏统一调节位置与大小。

### 预览区双向定位与直接拖拽

- **双向定位**：左键单击预览中的插图，右侧属性栏会自动跳转到该图的设置项；反之，在属性栏中单击插图缩略图，中间预览也会滚动到对应图片并短暂高亮。
- **拖拽缩放与移动**：选中所属题目或知识点后，拖动预览中图片右下角即可等比缩放；位于右侧环绕的图支持上下拖动微调，“自由位置”的图可任意拖动且文字自动绕排。

### 选择题的图片选项

当选择题选项本身是图片时：

- 在预览中拖动单个选项图片右下角只缩放这一张；按住 `Shift` 拖动则全部选项图一起等比缩放。
- 在属性面板 **选项图片** 分组中，可逐张设置宽度，或一键 **全部缩小 / 放大 10%**、**以某个选项为准统一大小**。图片调小后，选项会自动重新排为每行 2 项或 4 项。

## 2. 添加插图与自动框选

在属性栏点击 **添加题图 / 答案插图 / 解析插图 / 插图 / 背景配图**，会打开与“从图片导入”相同的插图窗口：

1. 选择图片文件、拖入图片或按 `Ctrl+V` 粘贴截图。
2. 软件在本地自动识别并框选其中的插图（自动避开文字行、答题括号与边框）；若想补充框选，直接在图上拖一个框即可自动收紧到图形边缘；不需要的框可直接删除或拖四角微调。
3. 未框选任何框时默认整张添加；存在框选时按阅读顺序批量添加。

## 3. 图像变清晰、去白底与调色

右键点击预览中的插图，或在属性栏的插图操作按钮中，都可以随时对当前图片做无损调优（全部支持 `Ctrl+Z` 撤销）：

| 功能 | 适用场景 | 效果说明 |
|---|---|---|
| **变清晰** | 低分辨率截图、教辅小图 | 清理灰底与杂点后，对小尺寸图片执行 FSRCNN ×3 超分放大，不改变原图几何结构与文字内容（导入窗口默认开启，支持点击对比处理前后） |
| **去白底** | 带浅色/白色底色的插图 | 将白色背景转为透明，彩色与深色线条保留实色 |
| **一键加深** | 扫描件、拍照图片偏淡发灰 | 自动校准黑白场对比度，让偏灰线条变清晰同时保留阴影层次 |
| **手动调色…** | 需要精细修图 | 并排对照原图与预览，实时调节亮度、对比度与饱和度（饱和度拉到最左即为纯黑白） |

::: tip 批量处理全卷插图
点击左侧大纲顶部的 **批量处理插图…**，可以一次浏览全卷的所有插图（含题图、答案/解析插图、知识点插图与综合题配图），勾选多张一次性执行 **变清晰**、**去白底** 或 **一键加深**。
:::

## 4. WorkBuddy 重绘为 SVG 矢量图（可选）

对于清晰度太差或线条破损严重的示意图，还可以借助 WorkBuddy 生成可无限放大的 SVG 矢量图：

1. 在“从图片导入”窗口勾选框左下角的 **重绘** 后点击 **让 WorkBuddy 重绘插图**，或在编辑界面的批量处理 / 右键快捷栏点击 **WorkBuddy 重绘**。
2. 到 WorkBuddy 中输入 `重绘插图`，收到的结果会在框上标出 `SVG`。
3. 软件会并排展示 **原图** 与 **SVG 重绘结果**，由你逐张核对确认后决定保留原图还是替换为 SVG（导出 Word 时自动栅格化保持兼容）。

::: warning 注意核对细节
AI 重绘不能保证 100% 还原坐标刻度、箭头方向或字母标注，建议每一张都与原图并排比对后再点击应用。
:::
