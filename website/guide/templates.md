# 格式预设与自制模板

软件通过 **格式预设（`preset.json`）** 与 **Word 模板（`template.docx`）** 控制导出文档的结构与页眉外观。

<TutorialVideo id="templates-custom" />

## 1. 四套内置格式预设

在“新建教学案”“从 Word 文档新建”时可选择预设，或在首页 **设置…** 中指定“导入时默认格式预设”：

| 预设名称 | 适用场景 | 核心特点 |
|---|---|---|
| **物理教学案 V1.0** | 常规物理新授 / 复习课 | 含大标题、栏目标题（知识梳理 / 例题精讲 / 课堂练习 / 课后练习 / 课堂总结）、题型分组与作业单；页眉加 `(教案)` / `(学案)`；导入时将 `【详解】` 转为 `【解析】` 并统一为黑色 |
| **物理知识点手册 V1.0** | 知识清单、考前默写 | 仅含大标题与“一、二、三……”知识点；**学生版将标为“重点”（红色加粗下划线）的文字、公式与表格内容自动挖空成横线**；页眉不加 `(教案)` / `(学案)` |
| **物理题型整理 V1.0** | 单题母题突破小页册 | 一份讲一道母题：例题、审题（灰底注释框）、解题（`思维过程 / 书写过程` 对照表）、易错提醒、题后归纳；题目不编号、默认 1.3 倍行距；学生版书写栏换为虚线格 |
| **数学教学案 V1.0** | 数学新授课 / 墨案迁移 | 栏目为知识梳理 / 例题精讲 / 课堂练习 / 课堂总结 / 课后练习；难度分 `A～E` 五级；默认开启审题与重点题；**从墨案导入的教案默认使用此预设** |

## 2. 自制与分享模板（三步完成）

内置模板只读，可复制一份在本地模板目录（默认为 `文档\教学案\模板\`，**升级软件不会覆盖**）中修改：

1. **复制模板**：首页进入 **模板…** → 选中接近的内置模板 → 点击 **复制为新模板**。
2. **按需修改**：
   - 改 `preset.json`：调整模板名、三级标题字体字号、栏目名、默认行距、审题/重点题开关、页眉文字与挖空规则等；
   - 改 `template.docx` / `header/`：替换学校 Logo、页眉电话、水印与页边距（需保留 `{{body}}` 占位符及原有样式名；不建议直接改正文/题目样式的字号缩进，以免预览与导出不一致）。
3. **载入与分享**：回到 **模板…** 点 **重新载入** 即可使用（有格式错误会显示中文提示）；点 **导出为 zip** 可发给其他老师用 **导入模板…** 直接安装。
