# 快速上手

**教学案制作（TeachingPlan）** 是一款面向教师的桌面排版工具：把题目、知识点、插图与教师解析放进同一份 `.tplan` 工程，预览确认页数与版式后，一键同时导出**教师版（教案）**与**学生版（学案）**两个 Word 文档。

## 1. 认识首页与教学案库

启动软件后进入类似 WPS 的首页，左侧栏分为常用操作与文件导航两部分：

- **快捷创建与打开**：`新建教学案`、`从 Word 文档新建`、`从墨案导入…`、`打开`
- **文件浏览**：
  - **最近**：快速打开近期编辑过的教学案
  - **教学案库**：默认路径为 `文档\教学案`，可以在其中新建子文件夹（例如按年级、章节分类）
  - **本地目录**：直接浏览桌面、文档、下载与电脑各磁盘

右侧文件列表支持以下操作：

| 操作 | 快捷方式 / 入口 |
|---|---|
| 打开教学案（或双击 Word 直接新建） | 双击文件 或 `Enter` |
| 重命名（同步修改 `.tplan` 真实文件名） | 右键 → 重命名 或 `F2` |
| 删除（移入系统回收站） | 右键 → 删除 或 `Delete` |
| 导出 Word / 在文件夹中显示 | 右键文件（或点条目右侧 `⋯`） |

::: tip 文件在软件外被移动或删除了？
在“最近”列表中右键失效条目选择 **从列表中移除**，或直接点击顶部的 **清除失效项** 即可整理干净。
:::

## 2. 新建第一份教学案

1. 在首页点击 **新建教学案**。
2. 输入教学案名称，并选择一份 **格式预设**（例如 `物理教学案 V1.0` 或 `数学教学案 V1.0`）。
3. 确认后软件会在教学案库中立即创建 `.tplan` 工程，并自动带入模板默认的页眉（Logo、电话、水印），随后进入编辑界面。

### 多标签页同时处理多份教学案

- 每打开一份教学案会在顶部占一个标签页，点击标签可切换（`Ctrl+Tab` / `Ctrl+Shift+Tab`）。
- 支持拖动标签调整排列顺序，点击标签上的 `×` 或用鼠标中键关闭（`Ctrl+W`）。
- 名称前带圆点表示尚未保存；点击左上角 **首页** 可以返回首页查看文件，同时保留已打开的标签页。

## 3. 熟悉三栏编辑界面

进入教学案后，界面分为左、中、右三栏（拖动分隔边界可自由调整左右栏宽度，双击边界恢复默认）：

1. **左侧大纲**：按大标题、栏目、题型分组、知识点与题目树状展示结构；点击大纲中的某一项，中间预览会自动滚动到它第一行所在位置（停在预览窗约 20% 高度处，方便看清整道题）。
2. **中间分页预览**：真实按 A4 纸张大小与页边距分页渲染，**预览效果与导出的 Word 保持一致**。顶部可以切换查看「学生版」或「教师版」预览效果。
3. **右侧属性面板**：选中某道题、知识点或标题后，在这里填写和修改具体内容。点击预览中的任意一行，右侧属性栏也会自动滚到对应输入框附近。

::: info 题目属性的“题目”页与“仅教师版”页
每道题右侧属性面板顶部都有两个切换页：
- **题目**：难度、变式题、题干、题图、选项、小问与版式；
- **仅教师版**：重点题标记、答案（及答案插图）、知识点、重点、难点、审题、解析（及解析插图）。

在预览中点击答案或解析时会自动切到“仅教师版”，点击题干或选项时自动切回“题目”。
:::

## 4. 一键导出教师版与学生版 Word

完成编辑后，点击顶栏 **导出 Word**（快捷键 `Ctrl+E`），或者在首页右键某个教学案直接选择 **导出 Word**：

- **教师版（教案）**：默认命名为 `(T)名称.docx`，包含题目、答案、解析、审题、重点题标记等完整内容；
- **学生版（学案）**：默认命名为 `(S)名称.docx`，隐藏答案与解析，并按设定的“整题同页”与“作答留白”排出留空；若使用知识点手册或题型整理预设，学生版还会自动将重点挖空成下划线或虚线书写格。
- **知识点重点难点汇总（可选）**：在导出对话框勾选后，还会额外生成一份 `(T)名称(知识点重点难点).docx`，按栏目汇总各题的知识点、重点、难点与审题（可在首页 `设置…` 中设为默认勾选）。

导出生成的 Word 文档沿用模板样式，题号、小问号与 `【答案】` 等标签均为 Word 自动编号，公式为 Word 原生公式、表格为 Word 表格，发给其他老师也能继续直接编辑。
