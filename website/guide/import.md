# 导入题目与知识点

除了从零手动录入，软件提供从 **Word 文档**、**图片（AI 识图）** 与 **墨案** 导入题目或知识点，尽量保留原有公式、表格、插图和题号结构。

## 1. 从 Word 文档导入

### 入口

- **整份新建**：在首页点击 **从 Word 文档新建**，或直接双击文件列表中的 `.docx` 文档。
- **追加导入**：在编辑界面点击 **导入题目 ▾ → Word 文档…**，导入的题目会插入到当前选中内容之后。

### 识别规则与保留内容

- **组卷网文档直导**：从组卷网下载的题目文档可以直接导入；题组（材料 + 若干小题）会自动整理为综合题并共用答案与解析；短标题、背景材料、配图、选项、小问都会识别；难度系数会自动换算为难度等级（`0.7` 以上 A、`0.5～0.7` B、低于 `0.5` C）；“学校:___ 姓名:___”及“系统分组”等干扰行会自动清理。
- **普通题集 / 教案文档**：使用“物理排版”样式的文档按样式精确识别；其他文档会按 `1.` 题号、`A.` 选项、`【答案】`、`【解析】` 等常见标记智能切分。
- **格式保留**：导入时会保留 MathType / EQ 域 / Word 原生公式、形状示意图、表格（合并单元格、列宽、底纹）、加粗、文字颜色与字体（自动归类为宋 / 黑 / 楷 / 仿宋）。
- **物理教学案预设特性**：导入时会自动将 `【详解】` 统一改为 `【解析】`，解析文字统一为黑色，并保留知识梳理中的红色、加粗与下划线标记，同时自动识别作业单。

## 2. 从图片导入（交给 AI 识别）

手头只有纸质试卷照片、教辅扫描页或截图时，可以使用 **导入题目 ▾ → 图片（交给 AI 识别）…**：

### 基本流程（通用 AI 方式）

1. **放入图片**：点击选择图片、直接拖入，或在窗口中按 `Ctrl+V` 粘贴截图。
2. **核对插图框选**：软件会在本地自动框出图中的插图（不依赖网络），并按阅读顺序标为 `[图1]`、`[图2]` 与识别结果对应。框可以拖动、拖拽四角微调或删除；如有漏框，在图上随手拖出一个框即可自动收紧到图形边缘。
3. **复制指令给 AI**：点击右侧 **复制给 AI 的指令**，连同题目图片一起发给任意擅长识图的 AI（例如 WorkBuddy、豆包、Kimi 等）。
4. **粘贴结果与即时检查**：把 AI 返回的代码块内容粘贴回软件右侧，下方会立刻显示识别出几道题、是否存在无法转换的公式或尚未框选的插图，核对无误后点击导入。

::: tip 插图处理同步完成
导入窗口默认开启 **插图变清晰**，可自动清理灰底杂点并对小图超分放大 3 倍；勾选 **去白底** 或点击 **一键加深** 后，点选插图还能实时对比处理前后的效果。
:::

### WorkBuddy 一键自动识别（免复制粘贴）

如果你在电脑上安装了 WorkBuddy，可以免去来回复制粘贴：

1. **首次配置**：打开首页 **设置… → WorkBuddy 自动识别 → 连接 WorkBuddy**（只需连接一次）。
2. **发起识别**：在“从图片导入”窗口放好图片后，点击 **交给 WorkBuddy 识别**。
3. **触发并自动回填**：切到 WorkBuddy 对话框中说一句 `导入题目`，识别与校验结果会自动传回导入窗口，检查后直接导入即可。

## 3. 从墨案导入

如果你之前在“墨案”平台整理过教案，可以直接整篇或整个文件夹迁移过来：

1. 在首页点击 **从墨案导入…**（或顶部菜单 **文件 → 从墨案导入…**），打开内置墨案窗口并登录账号（登录状态会自动保留）。
2. **单篇导入**：在窗口中打开一篇要迁移的教案，软件会询问是否导入。
3. **整夹批量导入**：进入墨案教案所在文件夹，点击窗口顶部菜单 **导入 → 导入当前文件夹的全部教案**，即可一次性全部导入。

### 迁移说明

- 迁移后的教学案默认使用 **数学教学案 V1.0** 预设，保存路径为 `教学案库\墨案导入`（批量导入文件夹时会按文件夹名归档），导入后自动在主窗口打开。
- 题目、变式题（`a. b. c.`）、答案、解析、LaTeX 公式、从 Word 粘贴的 MathML 公式、图片、作答留白、换页、难度（默认隐藏）以及解析中的 `审题：…`、标为“重点”的题目都会完整保留。
- 选项排在表格里的选择题会自动拆格取出选项（实验数据等普通表格则继续保留）。
- 若遇网络切换或页面加载异常，可在墨案窗口 **页面** 菜单中使用 **强制刷新（忽略缓存）** 或 **清除登录状态与缓存并刷新**；若导入异常，可通过 **导入 → 保存诊断文件** 保存脱敏诊断包反馈排查。

## 4. 导入知识点

如果需要往“知识梳理”栏目或知识点手册中批量录入知识条目：

- 点击工具栏 **导入知识点 ▾**，同样支持 **Word 文档** 与 **图片** 两种来源。
- 按照知识点模式识别时，以 `一、……` 写成的标题后紧跟正文会被识别为一个知识点块，条目下以 `1.` 开头的序号列表不会被误拆成题目。
