# 常见问题与主题设置

## 1. 软件设置与配色主题

在首页左侧栏点击 **设置…**，可以配置以下全局偏好：

- **教学案库位置**：指定 `.tplan` 工程与自制模板的默认存放目录。
- **导入时默认格式预设**：从 Word 文档新建或快速导入时默认采用的预设。
- **公式字母默认正斜体**：设置新建教学案时公式字母默认正体还是斜体。
- **默认导出知识点重点难点汇总**：开启后每次导出 Word 默认同时输出 `(T)名称(知识点重点难点).docx`。
- **WorkBuddy 自动识别**：点击一次 **连接 WorkBuddy** 完成本机配置。
- **配色主题**（点击立即生效并自动记住）：

::: info 主题只改软件界面，不影响排版与导出
无论切换到深色模式还是风格主题，中间的 A4 预览纸面始终保持白纸黑字，导出的 Word 文档也完全不受软件界面主题影响。
:::

### 七套内置配色主题

| 主题名称 | 类型 | 视觉风格说明 |
|---|---|---|
| **青灰**（默认） | 常规 | 安静的青灰工作台，配以克制的“批改红”强调色 |
| **暖纸** | 常规 | 柔和的米色纸面与偏棕墨色 |
| **雾蓝** | 常规 | 偏冷调的蓝灰工作台 |
| **素白** | 常规 | 不带色相的中性灰白，接近常见办公软件风格 |
| **深色** | 常规 | 暗色面板与工作台（公式输入框仍保持白底黑字便于核对） |
| **赤黑** | 风格主题 | 红黑白高反差、直角与斜切色块、剪报拼贴标题、悬停游移四边形、斜幕切页以及预览右键“战斗指令”式菜单 |
| **月潮** | 风格主题 | 深海蓝与青色辉光、逐字浮起标题、流光按钮以及三层海水灌入的标签页切换过场 |

选择“赤黑”或“月潮”后，“配色”下方会出现每项动效的独立开关，你可以按喜好关闭某一项（改回常规效果）；当系统开启“减弱动态效果”时，动画也会自动关闭。

## 2. 常用快捷键速查

| 场景 | 快捷键 | 功能 |
|---|---|---|
| **首页文件列表** | `Enter` | 打开选中教学案（或用 Word 新建教学案） |
| **首页文件列表** | `F2` | 重命名教学案并同步修改 `.tplan` 文件名 |
| **首页文件列表** | `Delete` | 将文件移到系统回收站 |
| **全局标签页** | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换到下一个 / 上一个已打开的教学案标签页 |
| **全局标签页** | `Ctrl+W`（或鼠标中键） | 关闭当前教学案标签页 |
| **编辑界面** | `Ctrl+E` | 打开导出 Word 对话框 |
| **编辑界面** | `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z` | 撤销 / 重做（最多 200 步） |
| **文字输入** | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 加粗 / 倾斜 / 下划线 |
| **选项图片缩放** | `Shift + 拖动右下角` | 全部选项图片一起等比缩放 |
| **表格单元格选择** | `Shift + 单击另一格` | 选中矩形区域以便合并单元格 |
| **大纲拖拽** | `Esc` | 取消当前拖拽排序 |

## 3. 常见使用问题

### 导出的 Word 可以发给没有安装本软件的老师打开吗？

可以。导出的是标准的 `.docx` 文档，题号、小问号与 `【答案】` 使用 Word 自动编号，公式为 Word 原生公式，表格为 Word 原生表格。其他老师无需安装本软件，用 Microsoft Word 或 WPS 即可直接打开和二次修改。

### `.tplan` 工程文件如何备份或分享给同事？

`.tplan` 是独立的单文件工程（内部为标准 ZIP 容器，所有题目、公式与插图图片都打包在里面）。直接把 `.tplan` 文件复制给同事，或者把整个「教学案库」文件夹同步备份即可。

### Windows / macOS 安装后首次打开被系统拦截怎么办？

由于软件为开源独立打包发布、未购买商业代码签名证书，Windows 遇 SmartScreen 拦截时点击 **更多信息 → 仍要运行**；macOS 遇“无法验证开发者”时进入 **系统设置 → 隐私与安全性** 点击 **仍要打开** 即可，详见 [下载安装说明](/download#安装注意事项)。

### 从墨案导入时遇到登录卡住或页面白屏怎么办？

在墨案导入窗口的顶部 **页面** 菜单中，可以依次尝试 **强制刷新（忽略缓存）**、**清除登录状态与缓存并刷新**；如果某篇教案导入失败，可点击 **导入 → 保存诊断文件**（已自动隐去登录凭证）以便定位问题。
