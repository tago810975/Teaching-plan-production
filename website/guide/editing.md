# 编辑与排版

在编辑界面中，所有改动都可以随时通过顶栏 `↶` `↷` 或 `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）撤销与重做，最多支持 **200 步**（同一处连续打字合并为一步）。

## 1. 题目与综合题

### 难度、变式题与题目可选项

- **难度等级**：物理预设默认分 `A ★ 简单`、`B ★★ 中等`、`C ★★★ 难`（数学教学案分 `A～E` 五级），可在大纲顶部的 **版式设置 → 难度显示** 选择显示样式或隐藏。
- **变式题**：在题目属性面板勾选 **变式题**，题号自动编为 `a. b. c.` 紧跟在上一道题之后，不占用数字题号（如 `1. a. b. 2. …`）。导出 Word 时数字题号仍保持自动编号。
- **重点题与审题**（所有题型均支持）：
  - 在属性面板 **仅教师版** 页勾选 **重点题**，教师版题干前会显示红色加粗的 `【重点题】`；
  - 填写 **审题** 内容后，教师版会将其排在解析之前，开头显示 `【审题】`。
  - 数学教学案默认开启这两项，其他预设可在 **版式设置 → 题目可选项** 中随时按需开启或关闭（关闭后只是暂不显示与排版，已填内容仍会保留）。

### 综合题与小题整理

- 综合题由 **标题**（如“材料一”）、可选的 **背景材料与配图** 以及 **若干小题** 组成，小题题号与全卷连续。
- **答案与解析排布**：可在综合题属性面板或右键快捷窗口中切换“集中在最后”或“分到各小题”，系统按题号自动拆开或合并（可撤销）。
- **小题跨综合题移动**：把小题上移到第一道之前、或下移到最后一道之后即可移出综合题；独立题目紧挨着综合题时上/下移即可并入；也可以通过右键快捷窗口的 **移到** 或直接在大纲中拖动。

### 作业单与分页重新编号

- 通过 **添加** 菜单中的预制模块插入 **作业单**，会自动从新的一页开始，生成大标题与“姓名 / 教室 / 正确率”栏，其后的题目自动从 `1` 重新编号。
- 大标题、栏目标题与题型分组也可在各自属性面板的 **版式** 中单独勾选 **从新的一页开始** 与 **之后的题号从 1 重新开始**。

## 2. 知识点、挖空重点与表格

### 知识点与“重点”标记

- 知识梳理按“一、二、三……”分组为知识点（包含标题、正文段落与插图），支持设置留白、跨页与换页；单个段落也可设置段后空行、从此段换页或从某段拆分为新知识点。
- 编辑知识点时，点击格式工具栏最前面的 **重点** 按钮，可将选中的文字或公式设为红色加粗下划线（再点一次取消）。在 **物理知识点手册** 预设中，学生版会自动将这些标了重点的内容挖空为下划线横线，方便课堂默写。

### 表格编辑

- 在输入框下方点击 **插入表格** 新建，或点击 **编辑表格** 进入表格编辑器（输入框内显示为 `⟦表格N⟧`，删掉它即删除表格）。
- 支持插入/删除行列、按住 `Shift` 连选多个单元格后 **合并单元格**、光标置于合并格内 **拆分单元格**、按厘米设置列宽或 **平均分布 / 自动**，内部同样支持格式工具（含“重点”）与撤销重做。
- 在中间预览区域中，还可以直接拖动表格的竖线调整列宽。
- 题型整理预设下可在表格编辑器中勾选“当前单元格在学生版换成书写横线 N 行”，使学生版自动生成虚线书写格。

## 3. 文字格式、填空与公式

- **文字格式**：在属性面板顶部工具栏使用 `B / I / U`（或 `Ctrl+B / I / U`）设置加粗、倾斜、下划线，使用 `红 / 黑 / 蓝` 设置文字颜色（选“黑”恢复默认）。在预览中直接选中文字或公式，上方也会弹出浮动工具条，还可快速设置段落左对齐 / 居中 / 右对齐。
- **填空横线**：在编辑框中输入至少 3 个连续下划线（如 `____`），每 2 个下划线代表 1 个字宽，增减下划线即可直观控制横线长度。
- **字体**：各输入框标题旁可单独指定字体（随样式 / 宋体 / 黑体 / 楷体 / 仿宋），预览与导出 Word 一致。
- **可视化公式**：点击 **插入公式** 在光标处插入新公式；在预览中直接点击已有公式即可调出可视化编辑面板（附带常用模板按钮与数学键盘）。选中公式标记 `⟦公式N⟧` 也可为其加粗、加下划线或设颜色。
- **公式字母正斜体**：默认采用正体字母（与物理常用规范一致），每份教学案可在 **版式设置 → 公式字母** 中一键切换正体或斜体，也可在首页 `设置…` 中设置全局默认。从 Word 导入且未做修改的公式在导出时原样保留。

## 4. 版式设置、快捷窗口与大纲拖拽

### 全局与单题版式

- 点击大纲顶部的 **版式设置**，可分别设定教案与学案是否允许题目跨页（默认教案允许跨页省纸、学案整题同页）、难度显示方式、题目可选项、选项列间距方案（支持自定义修改各列起始字宽并“另存为方案”供全局复用），以及标题 / 题目 / 知识点 / 正文段落的 **行距倍数**。
- 单道题目也可以在自身属性面板底部的 **版式** 区域单独覆盖选项排布（每行几项）、题后留白、整题同页、换页以及本题独立的选项位置。

### 快捷版式窗口

在中间预览或左侧大纲中 **右键点击** 任意一道题、知识点、综合题或标题，即可弹出快捷版式窗口，直接修改难度、选项排布、整题同页、题后留白、换页、重编题号、综合题答案位置、移动目标以及上移 / 下移（支持连续点击）与删除。

### 左侧大纲拖拽排序

- 在左侧大纲按住某一项约 `0.3 秒` 即可开始拖动，松手后落入蓝色插入线位置；拖动期间滚动鼠标滚轮可快速翻页，拖到列表上下边缘会自动滚动，按 `Esc` 取消。
- 题目（含综合题内的小题）可拖进或拖出综合题：拖到综合题末尾时，鼠标偏右（插入线缩进）表示放进综合题，偏左表示放在综合题后面。
